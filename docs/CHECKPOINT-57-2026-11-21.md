## User-reported incident
- Solo OBS previously worked in third-party streaming apps.
- Current behavior: streaming apps show a blank overlay; iOS returns HTTP 404.
- Live session is time-critical.

## Changes committed
- `src/app.js`: resolve `overlay.html` from `document.baseURI` rather than deriving the output path from the module URL. This anchors the generated link to the deployed site root and avoids a path-resolution mismatch when the app is hosted under a GitHub Pages project path or a custom base URL.
- `overlay.html`: display the status panel whenever the overlay is in a visible status/error state, not only when debug mode is enabled. This exposes boot/API/configuration failures that previously appeared as a blank canvas.
- `overlay.html`: update the overlay module cache-bust to `20261121-obs-blank-hotfix-1`.
- `tests/project-smoke.test.mjs`: add a regression assertion for page-root URL resolution and visible diagnostics.
