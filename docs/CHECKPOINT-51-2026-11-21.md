## User-reported issue

Accessories/stickers could not be dragged directly on the avatar preview. The previous UI exposed separate accessory rows and minus/plus scale steppers, rather than a single selected-item editor with complete transform controls.

## Root cause found

The pointer handler assigned to `accessoryDragState` without a declaration in the ES module. ES modules execute in strict mode, so the assignment could throw a `ReferenceError` when pointer-down reached that statement. The previous hit-test also fell back to dragging the selected accessory after a pointer-down anywhere on the canvas, which made selection behavior unreliable.

## Implemented changes

1. Declared accessory drag state and per-item save timers.
2. Replaced the old accessory rows with a dropdown selector.
3. Added selected-accessory controls for Scale, Rotation, Position X and Position Y.
4. Added immediate preview updates and debounced persistence during slider movement.
5. Added pointer capture and cleanup for pointer-up, pointer-cancel and lost-pointer-capture.
6. Dragging begins only when the pointer intersects an accessory's transformed bounds.
7. Hit testing now accounts for avatar-follow transforms and per-accessory rotation.
8. Added per-accessory rotation rendering around the sticker center.
9. Added cache-busting versions for the app and CSS.
10. Added regression coverage for pointer state, controls, transformed bounds and renderer rotation.

4. Adjust Scale, Rotation, X and Y. Confirm preview updates immediately.
5. Refresh the page and reopen the character. Confirm all transforms remain.
6. Upload/select a second sticker. Confirm moving or rotating the first does not affect the second.
