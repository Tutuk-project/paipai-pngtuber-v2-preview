## Changes committed to Preview main
- `src/avatar-renderer.js`: render to a bounded internal canvas (maximum long edge 1280 px), then publish a completed frame to the visible output. When the next avatar frame is not ready, the last valid visible frame is retained instead of clearing the OBS canvas. Distortion slicing was reduced from 48 rows to a resolution-based 12–20 rows.
- `src/overlay.js`: Collaboration OBS compositor draws the 3×3 composition grid when any visible room member has `overrides.showGrid=true`.
- `src/app.js`: added a room-scoped ON/OFF toggle, persisted through `set_room_override`, and included in the `player-layout` realtime broadcast. Creator preview draws the same grid over the shared stage.
- `index.html`: Collaboration stage canvas initial dimensions changed to 1920×1080.
- `assets/app.css`: Collaboration stage wrapper/canvas constrained to a responsive 16:9 landscape presentation.
- `supabase/functions/vio-api/index.ts`: allowlisted and boolean-validated the `showGrid` room override.
- `tests/security-hardening.test.mjs`: added source regression assertions for bounded frame publishing and grid persistence/rendering.
