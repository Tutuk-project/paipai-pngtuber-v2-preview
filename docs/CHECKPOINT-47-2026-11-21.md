# Vio Studio v2.0 — Checkpoint 47
Date: 2026-11-21

## User-reported regressions after Checkpoint 46
1. The web editor became severely laggy.
2. Solo OBS microphone capture and Idle/Talking expression switching worked, but the avatar sometimes disappeared.
3. Continuous avatar motion such as breathing and related animation did not appear to run.
4. GO Collaboration was not retested because the web editor was too laggy.

## Source-level findings
- Solo OBS rendered each player into a separate offscreen canvas. The visible OBS stage was copied only when a state or room event called `render()`; the offscreen renderer's continuous animation frames were not continuously propagated to the visible stage. This explains why mic-driven expression changes could work while breathing/sway/bounce were not visible.
- The renderer selected only the currently requested expression asset URL. If that state-specific asset was unavailable or still loading, it could draw nothing even if another expression asset was already decoded. This is a plausible source of intermittent avatar disappearance.
- The Creator editor preview used the full saved stream backing dimensions (commonly 1080×1920) for a small on-screen preview, doing unnecessary full-resolution drawing on mobile.
- The Collaboration Creator preview composited a 1920×1080 canvas on every display animation frame (commonly 60 fps), in addition to each participant renderer's own animation loop.

## Changes made in Preview repository main
- `src/overlay.js`: Solo personal overlays now render directly into the visible OBS stage canvas, so the AvatarRenderer animation loop paints the actual output. Multi-participant Collaboration overlays retain separate player canvases and use a 30 fps compositor. The compositor is cancelled on pagehide and when no participants remain.
- `src/avatar-renderer.js`: expression selection now prefers a decoded image and falls back to any decoded Idle/Talking/Blink asset while the requested state-specific asset is loading or unavailable.
- `src/app.js`: editor-only avatar preview backing resolution is capped to a 720 px long edge while preserving the configured stream output dimensions in profile preferences and aspect ratio.
- `src/app.js`: Collaboration Creator preview compositing is throttled to 30 fps; the logical landscape stage remains 1920×1080.
- `tests/security-hardening.test.mjs`: regression assertions added for direct Solo canvas animation, expression image fallback, bounded editor preview resolution, and 30 fps Collaboration preview compositing.
